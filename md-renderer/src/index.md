# Welcome to MD Renderer

This is a static site generator built with 11ty for rendering markdown files to HTML.

## Features

- Simple markdown to HTML conversion
- Fast build times
- Flexible template system
- Easy to extend

## Getting Started

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Structure

```
src/
├── _includes/     # Reusable template components
├── _layouts/      # Page layouts
├── css/           # Stylesheets
├── js/            # JavaScript files
└── *.md           # Content files
```
