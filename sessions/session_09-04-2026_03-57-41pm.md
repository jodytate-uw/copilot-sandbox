## Notes

Git will not let a repository activate `core.hooksPath` on clone, by design — that would allow arbitrary code execution on checkout. Client-side hooks therefore always require one manual `git config` per clone. Only a server-side check (CI or a push ruleset) enforces conventions unconditionally.
